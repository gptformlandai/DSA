#### B) Matrix Rotation & Transformation (6 problems)

   * Two rotations OR reverse rows \+ columns  
10. **Transpose Matrix**  
    * Convert rows to columns  
    * Key: Swap \[i\]\[j\] with \[j\]\[i\]  
11. **Set Matrix Zeroes** ⭐⭐  
    * Set entire row/col to zero  
    * Key: In-place marking using first row/col  
    * **AMAZON FAVORITE**

    * Convert m×n to r×c  
    * Key: Linear mapping  
13. **Flip Image** ⭐  
    * Horizontal flip \+ invert  
    * Key: Two-pointer in each row

#### C) Matrix Search (5 problems)

## **🎯 Key Matrix Patterns to Memorize**

### **Pattern 1: Spiral Traversal Template**

def spiralOrder(matrix):  
    result \= \[\]  
    top, bottom \= 0, len(matrix) \- 1  
    left, right \= 0, len(matrix\[0\]) \- 1  
      
    while top \<= bottom and left \<= right:  
        \# Right  
        for col in range(left, right \+ 1):  
            result.append(matrix\[top\]\[col\])  
        top \+= 1  
          
        \# Down  
        for row in range(top, bottom \+ 1):  
            result.append(matrix\[row\]\[right\])  
        right \-= 1  
          
        \# Left (if still valid)  
        if top \<= bottom:  
            for col in range(right, left \- 1, \-1):  
                result.append(matrix\[bottom\]\[col\])  
            bottom \-= 1  
          
        \# Up (if still valid)  
        if left \<= right:  
            for row in range(bottom, top \- 1, \-1):  
                result.append(matrix\[row\]\[left\])  
            left \+= 1  
      
    return result

### **Pattern 2: In-Place 90° Rotation**

def rotate(matrix):  
    n \= len(matrix)  
      
    \# Transpose  
    for i in range(n):  
        for j in range(i \+ 1, n):  
            matrix\[i\]\[j\], matrix\[j\]\[i\] \= matrix\[j\]\[i\], matrix\[i\]\[j\]  
      
    \# Reverse each row  
    for row in matrix:  
        row.reverse()

### **Pattern 3: Staircase Search (Search 2D Matrix II)**

def searchMatrix(matrix, target):  
    if not matrix:  
        return False  
      
    row, col \= 0, len(matrix\[0\]) \- 1  \# Start top-right  
      
    while row \< len(matrix) and col \>= 0:  
        if matrix\[row\]\[col\] \== target:  
            return True  
        elif matrix\[row\]\[col\] \> target:  
            col \-= 1  \# Move left  
        else:  
            row \+= 1  \# Move down  
      
    return False

def buildPrefixSum(matrix):  
    m, n \= len(matrix), len(matrix\[0\])  
    prefix \= \[\[0\] \* (n \+ 1\) for \_ in range(m \+ 1)\]  
      
    for i in range(1, m \+ 1):  
        for j in range(1, n \+ 1):  
            prefix\[i\]\[j\] \= matrix\[i-1\]\[j-1\] \+ \\  
                          prefix\[i-1\]\[j\] \+ \\  
                          prefix\[i\]\[j-1\] \- \\  
                          prefix\[i-1\]\[j-1\]  
    return prefix

def rangeSum(prefix, r1, c1, r2, c2):  
    \# Sum of submatrix from (r1,c1) to (r2,c2)
