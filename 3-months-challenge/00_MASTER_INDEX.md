# 🏆 INTERVIEW DAY QUICK REVIEW

## 30-Minute Refresh Checklist

### Data Structures (5 min)
- [ ] Array: Two pointers, Sliding window, Prefix sum
- [ ] Stack: Monotonic stack, Matching pairs
- [ ] Linked List: Fast-slow pointers, Reversal
- [ ] Tree: Recursion template, BFS/DFS
- [ ] Graph: BFS, DFS, Union-Find, Topo sort
- [ ] Heap: Top K, Two heaps

### Algorithms (5 min)
- [ ] Binary Search: Standard, Rotated, On answer
- [ ] DP: State definition, Recurrence, Base case
- [ ] Backtracking: DO-RECURSE-UNDO
- [ ] Greedy: Sort first, Local optimal

### Complexity (2 min)
- [ ] O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
- [ ] Space: In-place vs Extra space

### Edge Cases (3 min)
- [ ] Empty input
- [ ] Single element
- [ ] All same elements
- [ ] Negative numbers
- [ ] Integer overflow

### Communication (5 min)
- [ ] Clarify requirements
- [ ] Discuss approach before coding
- [ ] Think out loud
- [ ] Test with examples
- [ ] Analyze complexity
