# Section 28 - MAANG Hot Problem Solutions

> Goal: turn the roadmap into an interview-prep machine by pairing the Hot 150/200 problem list with repeatable, interviewer-friendly solution writeups.

---

## How To Use This Section

Use this section after you have read the topic notes once.

1. Pick a problem from `01_Hot_150_Index.md`.
2. Try it for 20-35 minutes without looking at the solution.
3. If stuck, read only the pattern and intuition.
4. Re-code from memory.
5. Explain the answer using the interview script.
6. Mark it as solved only after you can solve it again the next day.

## Completion Standard

A problem is truly done when you can:

- [ ] Identify the pattern in under 60 seconds
- [ ] Explain the state/invariant before coding
- [ ] Code the solution without notes
- [ ] Dry run on a non-trivial example
- [ ] State time and space complexity
- [ ] Mention at least one common edge case
